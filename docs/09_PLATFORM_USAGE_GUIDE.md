# 📘 دليل الاستخدام الشامل لمنصة درب للكتب التفاعلية

> **نظرة شاملة على منظومة درب، أوضاع التشغيل، الأدوار المتكاملة، وتجربة الاستخدام الكاملة للقارئ والمؤلف والمراجع ومدير المنصة.**

---

## 1. ما هي منصة درب؟

منصة **درب** نظام سحابي متكامل للنشر والقراءة التفاعلية ثلاثية الأبعاد، صُمم ليدعم جميع المراحل التعليمية (من التمهيدي ورياض الأطفال وحتى الدكتوراه والبروفيسوراه والقراءة العامة) ومختلف أنواع المحتوى (الكتب التعليمية التفاعلية، المراجع التشريحية والتقنية، القصص والروايات، المجلات العلمية، والمختبرات الافتراضية).

### الركائز الأساسية للمنصة
1. **تجربة قراءة ثلاثية الأبعاد غامرة:** تقليب ورقي واقعي من اليمين لليسار (`RTL`) أو من اليسار لليمين (`LTR`) مع إضاءة مجسمة، وثلاثة أنماط عرض (**مخطوطة كلاسيكية**، **الوضع الليلي**، **الوضع النهاري**)، وثلاثة أحجام خطوط.
2. **الوسائط المتزامنة والقراءة دون إنترنت:** راوٍ صوتي فصيح متزامن مع كل نشرة مع خيارات التسريع والانتقال، وعروض فيديو للفصول، وإمكانية حفظ الكتاب كاملاً للقراءة والاستماع دون اتصال بالإنترنت.
3. **ست كتل تفاعلية غنية داخل الصفحات وفي المختبر الكامل:**
   - **عارض المجسمات ثلاثية الأبعاد:** تدوير وتفكيك الطبقات ونقاط شرح تفاعلية.
   - **مختبرات المحاكاة:** محاكاة للفيزياء والرياضيات والعلوم بمعاملات حية.
   - **الخرائط والخطوط الزمنية:** استكشاف جغرافي وتاريخي تفاعلي.
   - **مختبر اللغة والقرآن:** ترميز التجويد والتشكيل وتمارين الإملاء.
   - **مختبر البرمجة الآمن:** كتابة وتجربة الأكواد في بيئة معزولة داخل المتصفح.
   - **تخطيط القصص والمجلات:** حوارات متسلسلة واقتباسات واستطلاعات للقراء.
4. **مرونة كاملة وحماية عمرية:** إدارة مركزية عربية لكل التصنيفات والمستويات، وهوية المنصة، وسياسات التسجيل، دون قيود جامدة.

| الوضع | كيف يعمل؟ | الصفحات والقدرات المتاحة |
| :--- | :--- | :--- |
| **الوضع الحي الكامل (متصل بالخادم)** | يتصل بواجهة الخادم (`apps/api`) وقاعدة البيانات (PostgreSQL أو PGlite المحلي المستمر via `npm run dev:local`). | جميع القدرات: الحسابات، التهيئة التعليمية، التصفية العمرية، المزامنة السحابية، بوابة المؤلف، بوابة المراجعة، ولوحة التحكم الكاملة. |

## 4. الأدوار التشغيلية وتدفق العمل المتكامل

1. **القارئ / الطالب / الباحث:** يسجّل حسابه، يكمل التهيئة لتحديد فئته العمرية ومستواه وتخصصاته، فيجد المكتبة مخصّصة له تلقائياً مع حفظ تقدمه وإشاراته عبر أجهزته.
2. **المؤلف / الناشر / الأستاذ:** يحمّل القالب القياسي من بوابة المؤلف، يرفع كتابه بصيغة معتمدة، يعاينه في القارئ ثلاثي الأبعاد، ثم يوقّع إقرار الملكية الفكرية ويرسله للمراجعة، ويمكنه لاحقاً رفع إصدارات أحدث (`v2`, `v3`) دون تعطيل النسخة المنشورة حالياً.
3. **المراجع العلمي ومدقق الملكية الفكرية:** يستلم الإصدار من طابور المراجعة، يفحصه في القارئ 3D، يتحقق من بنود قائمة الفحص المعتمدة وسلامة المحتوى والملكية الفكرية، ثم يعتمده لينتقل فوراً للمكتبة أو يطلب تعديلات بملاحظات واضحة.
4. **مدير المنصة والإدارة العليا:** يدير كل تفاصيل الواجهة والتصنيفات والسياسات والأدوار والمستخدمين من لوحة التحكم المعربة دون تعديل الشيفرة، ويراقب كل حدث عبر سجل التدقيق القابل للتصدير والمشاركة.
