# ⚙️ الدليل المرجعي الشامل للوحة التحكم المركزية المرنة

> **مرجع تشغيلي تفصيلي لكل تبويب، وبطاقة، وحقل، وزر، وقائمة، وجدول، ونافذة داخل لوحة التحكم المركزية المعربة بالكامل في منصة درب.**  
> **المسار في البوابة:** `/admin` (عبر زر **«⚙️ لوحة التحكم»** في الشريط العلوي) — مقتصر على الحسابات المتصلة بالخادم الحي والتي تملك واحدة أو أكثر من صلاحيات الإدارة.

---

## 1. مدخل لوحة التحكم وقواعد الصلاحيات الديناميكية

عند الدخول إلى صفحة **«⚙️ لوحة التحكم المركزية المرنة»** ([`AdminLayout.tsx`](../apps/web/src/admin/AdminLayout.tsx)):
- **الجانب الأيمن (شريط التبويبات):** لا يعرض إلا الأقسام التي يملك حسابك صلاحيةً عليها من قاعدة البيانات، وتشمل التبويبات الخمسة التالية:
  1. **📝 الرئيسية والأخبار:** يظهر لمن يملك صلاحية تحرير الصفحة الرئيسية أو إدارة الأخبار.
  2. **🏷️ التصنيفات والمستويات:** يظهر لمن يملك صلاحية إدارة التصنيفات.
  3. **🎨 الهوية والتهيئة:** يظهر لمن يملك صلاحية إدارة تهيئة المنصة والهوية.
  4. **🛡️ الأدوار والمستخدمون:** يظهر لمن يملك صلاحية إدارة الأدوار أو إدارة المستخدمين.
  5. **📋 سجل التدقيق:** يظهر لمن يملك صلاحية الاطلاع على سجل التدقيق.
- **شارة الصلاحيات النشطة:** تظهر أعلى اللوحة بعدد الصلاحيات الفعلية المسندة لدورك الحالي.
- **في وضع العرض الثابت أو عند نقص الصلاحيات:** تظهر بطاقة تنبيه عربية توضح أن لوحة التحكم تتطلب الاتصال بالخادم الحي أو امتلاك الصلاحية المناسبة.

---

## 2. التبويب الأول: 📝 الرئيسية والأخبار

يدير هذا التبويب محتوى الصفحة الرئيسية للمنصة والأخبار المنشورة دون كتابة أي شيفرات أو نصوص برمجية خام ([`CmsAndNewsManager.tsx`](../apps/web/src/admin/CmsAndNewsManager.tsx)).

### أ. محرر أقسام الصفحة الرئيسية
#### جدول الأقسام
| العمود | الوصف |
| :--- | :--- |
| **نوع القسم** | الاسم العربي المقروء لطبيعة القسم (مثل: الواجهة الترحيبية الرئيسية، مميزات القراءة الغامرة، كيف تعمل المنصة). |
| **العنوان الظاهر** | العنوان العربي الذي يراه الزائر في الصفحة الرئيسية. |
| **الترتيب** | رقم تسلسل ظهور القسم من الأعلى للأسفل. |
| **الحالة** | `🟢 ظاهر` للقسم النشط أو `⚪ مخفي` للقسم المعطّل مؤقتاً. |
| **تحرير** | زر **«✏️ تعديل»** لفتح النموذج المرئي لتحرير محتوى القسم. |

#### النموذج المرئي لتحرير أي قسم
بعد النقر على **«✏️ تعديل»** تظهر الحقول التالية:
- **عنوان القسم الرئيسي:** حقل نصي لتعديل العنوان الظاهر.
- **ترتيب العرض:** حقل رقمي يتحكم بموضع القسم بين بقية الأقسام.
- **مفتاح التشغيل «إظهار القسم في الصفحة الرئيسية»:** مفتاح تبديل بصري لإخفاء القسم أو إظهاره فوراً دون حذفه.
- **الحقول المرئية المخصصة لنوع القسم (بديلاً كاملاً عن تحرير JSON):**
  - **الواجهة الترحيبية الرئيسية:** حقول لـ الشارة الترحيبية أعلى العنوان، الوصف الترحيبي، نص ووجهة الزر الأساسي، نص ووجهة الزر الثانوي الاختياري.
  - **مميزات القراءة الغامرة:** قائمة بطاقات مرئية (أيقونة، عنوان الميزة، وصف الميزة) مع أزرار **«➕ إضافة ميزة»**، **«↑ للأعلى»**، **«↓ للأسفل»**، و**«حذف الميزة»**.
  - **إمكانات المنصة التعليمية:** قائمة نقاط مرئية مع أزرار **«➕ إضافة نقطة»**، أسهم التحريك، و**«حذف»**.
  - **كيف تعمل المنصة:** قائمة خطوات مرقّمة تلقائياً (عنوان الخطوة، وصف الخطوة) مع أزرار **«➕ إضافة خطوة»**، التحريك، والحذف.
  - **أبرز الكتب والإصدارات المعتمدة** و**معاينة آخر الأخبار:** حقل رقمي يحدد عدد العناصر المعروضة.
  - **تذييل الصفحة والروابط السريعة:** حقل نص حقوق النشر، وقائمة مرئية لروابط التذييل (تسمية الرابط + المسار) مع زر **«➕ إضافة رابط»** و**«حذف»**.
  - **الأقسام المخصصة:** عنوان فرعي اختياري، محتوى نصي، زر اختياري (نص + رابط)، وقائمة بطاقات مرئية (أيقونة، عنوان، وصف) مع أزرار الإضافة والترتيب والحذف.
- **إعدادات تقنية متقدمة (قسم مطوي اختياري):** يعرض المعرّف الداخلي للقسم عند الحاجة الإدارية دون إزعاج المستخدم العادي.
- **الأزرار:** **«💾 حفظ وتحديث الرئيسية»** لتطبيق التعديل فوراً على الواجهة، و**«إلغاء»** لإغلاق نموذج التحرير.

### ب. إضافة قسم مخصص جديد إلى الصفحة الرئيسية
- **عنوان القسم:** يُكتب بالعربية (مطلوب)، ويقوم النظام **بتوليد المعرّف البرمجي تلقائياً** في الخلفية أثناء الكتابة.
- **عنوان فرعي (اختياري):** سطر توضيحي يظهر تحت العنوان.
- **المحتوى النصي:** فقرة النص المعروضة للزوار.
- **بطاقات اختيارية داخل القسم:** باني بطاقات مرئي لإرفاق بطاقات مصغرة بالأيقونة والعنوان والوصف.
- **إعدادات تقنية متقدمة (مطوية):** تتيح الاطلاع على المعرّف المولّد تلقائياً أو تعديله يدوياً، ثم زر **«إضافة القسم»**.

### ج. إدارة الأخبار والتحديثات
- **جدول الأخبار:** يعرض عنوان الخبر، ملخصه، وحالته المعرّبة (**منشور** / **مسودة** / **مؤرشف**)، مع زري **«أرشفة / نشر»** و**«حذف»**.
- **نموذج «➕ نشر خبر جديد»:** يتضمن عنوان الخبر (ويولّد المعرّف اللاتيني تلقائياً من العنوان)، ملخصاً قصيراً اختيارياً، ونص الخبر، وقسماً مطوياً «إعدادات تقنية متقدمة» لتخصيص رابط الخبر عند الرغبة، ثم زر **«نشر الخبر الآن»**.

## 3. التبويب الثاني: 🏷️ التصنيفات والمستويات

يتحكم هذا التبويب بجميع المجموعات والقيم التي تبني فلاتر المكتبة، وشاشة التهيئة الأولى، وربط الكتب، وضوابط الأمان العمري ([`TaxonomiesManager.tsx`](../apps/web/src/admin/TaxonomiesManager.tsx)).

### أ. نموذج إضافة تصنيف أو مستوى تعليمي أو مجموعة مخصصة
1. **المجموعة (قائمة اختيار عربية):** اختر من القيم المهيأة (**الفئة العمرية**، **المستوى التعليمي**، **التخصص / المجال**، **نوع الكتاب**) أو اختر **«مجموعة مخصصة أخرى»** ليظهر حقل إدخال باسم المجموعة الجديدة.
2. **التسمية بالعربية:** الاسم الذي يظهر للمتعلمين والمؤلفين في القوائم والبطاقات؛ ويقوم النظام تلقائياً بتوليد المعرّف البرمجي في الخلفية فور كتابتك بالعربية.
3. **ترتيب الظهور:** رقم يحدد ترتيب العنصر ضمن مجموعته.
4. **الضوابط والخصائص المرئية (بديلاً عن قواعد JSON):**
   - عند اختيار **الفئة العمرية:** تظهر ثلاثة حقول رقمية واضحة: **الحد الأدنى للعمر**، **الحد الأقصى للعمر** (يُترك فارغاً إذا كان مفتوحاً دون حد أقصى)، و**رتبة التصفية العمرية**.
   - عند اختيار **المستوى التعليمي:** يظهر حقل **ترتيب المستوى التعليمي** مع باني **خصائص إضافية اختيارية** (اسم الخاصية + القيمة مع زر **«➕ إضافة خاصية»**).
   - لبقية المجموعات: يظهر باني الخصائص الاختيارية مباشرةً.
5. **إعدادات تقنية متقدمة (مطوية):** لتعديل المعرّف البرمجي اللاتيني أو إضافة التسمية الإنجليزية الاختيارية.
6. **زر «إضافة التصنيف»:** يضيف التصنيف ويحدّث القوائم وواجهة المكتبة فوراً.

### ب. جدول التصنيفات الحالية
- **مرشح المجموعة (القائمة المنسدلة أعلى اليسار):** لتصفية الجدول حسب «جميع المجموعات» أو مجموعة محددة بالاسم العربي.
- **أعمدة الجدول:** **المجموعة** (بالعربية)، **الاسم العربي**، **الضوابط والخصائص** (ملخص مقروء للنطاق العمري أو الخصائص)، **الترتيب**، **الحالة** (`🟢 مفعل` / `🔴 معطل`)، وعمود **تحكم** الذي يضم أزرار **«↑»** و**«↓»** لإعادة الترتيب المباشر، وزر **«تعطيل / تفعيل»**.

## 4. التبويب الثالث: 🎨 الهوية والتهيئة

يدير الإعدادات المركزية السبعة للمنصة عبر نماذج بصرية متخصصة بالكامل ([`SystemConfigsManager.tsx`](../apps/web/src/admin/SystemConfigsManager.tsx)).

### شرائح اختيار الإعداد (الأزرار العلوية)
تظهر الشرائح بمسميات عربية واضحة، وبضغط أي شريحة يتغيّر النموذج المرئي أسفلها فوراً:

| الإعداد | الحقول المرئية المتوفرة |
| :--- | :--- |
| **الهوية البصرية والمظهر** | • **اسم المنصة** و**وصف المنظومة**<br>• **مسار الشعار** مع معاينة فورية للصورة<br>• **منتقي ألوان** (`Color Picker`) + عرض القيمة اللونية لكل من اللون الأساسي واللون الثانوي المميز<br>• قائمتان منسدلتان لـ **الثيم الافتراضي للزوار** (`مخطوطة كلاسيكية` / `الوضع الليلي` / `الوضع النهاري`) و**حجم الخط الافتراضي** (`صغير` / `متزن` / `كبير`) |
| **سياسة التسجيل والحسابات** | • أزرار اختيار واضحة لـ **آلية تفعيل الحسابات الجديدة** (`تفعيل فوري مباشرة بعد التسجيل` / `التحقق عبر البريد الإلكتروني أولاً` / `بانتظار موافقة الإدارة المسبقة`)<br>• مفتاح تبديل لـ **السماح بإنشاء الحسابات الذاتية**<br>• مفتاح تبديل لـ **إلزام المستخدم باستكمال التهيئة التعليمية عند أول دخول**<br>• حقل رقمي لـ **الحد الأدنى لطول كلمة المرور** وقائمة اختيار لـ **الدور الافتراضي للمسجلين الجدد** |
| **مفاتيح ميزات المنصة** | • 8 مفاتيح تشغيل وإيقاف بصرية (`Toggle Switches`) بالعربية لكل ميزة: المسرح ثلاثي الأبعاد، الراوي الصوتي، عروض الفيديو، الحفظ دون اتصال، الإشارات المرجعية، البحث الفوري، مصغّرات الصفحات، ومشاركة الروابط |
| **قائمة التحقق للمراجعة** | • محرر بنود مرئي يعرض بنود المراجعة الحالية مع نص كل بند، ومربع اختيار **«بند إلزامي للاعتماد / اختياري»**، وزر **«حذف البند»**، وزر **«➕ إضافة بند مراجعة»** في الأعلى |
| **سياسة رفع الملفات** | • شرائح تفعيل للصيغ المسموح برفعها في بوابة المؤلف بتسميات عربية واضحة، وحقل رقمي لـ **الحد الأقصى لحجم الملف (ميجابايت)** |
| **إعدادات القالب القياسي** | • حقل **رقم إصدار القالب الرسمي**، وحقل **عنوان القالب الرسمي**، ومربع نص **إرشادات المؤلفين المرفقة مع القالب** |
| **سياسة الأمان العمري** | • مفتاح تبديل لـ **تفعيل التصفية العمرية الصارمة على الكتب في المكتبة**<br>• مفتاح تبديل لـ **تطبيق القيود العمرية أيضاً على الزوار غير المسجلين**<br>• حقل رقمي لـ **الحد الأدنى للعمر للكتب غير المصنفة (سنوات)** |

- **إعدادات تقنية متقدمة (مطوية):** تتيح عرض المفتاح التقني، والتصنيف، وتبديل إتاحة الإعداد للواجهة العامة قبل تسجيل الدخول.
- **زر «💾 حفظ التهيئة وتطبيقها فوراً»:** يرسل القيم للخادم ويحدّث هوية المنصة وسلوكها لحظياً.

## 5. التبويب الرابع: 🛡️ الأدوار والمستخدمون

يدير نظام الصلاحيات الدقيق وحسابات المستخدمين ([`RbacAndUsersManager.tsx`](../apps/web/src/admin/RbacAndUsersManager.tsx)).

### أ. إنشاء دور وظيفي مخصص
- **اسم الدور بالعربية:** مثل «مشرف المحتوى المدرسي»؛ يولّد النظام رمزه البرمجي القياسي (`UPPER_SNAKE_CASE`) في الخلفية تلقائياً أثناء الكتابة.
- **وصف الدور (اختياري):** توضيح موجز لمهمة الدور.
- **الصلاحيات المرتبطة بالدور:** شرائح عربية تفاعلية لجميع الصلاحيات الـ 12 تُفعّل وتُعطّل بنقرة واحدة مع إشارة `✓` (دون إظهار أكواد برمجية مزعجة).
- **إعدادات تقنية متقدمة (مطوية):** لعرض أو تعديل الرمز البرمجي للدور عند الرغبة.
- **زر «إنشاء الدور المخصص»:** ينشئ الدور ويسجله في جدول الأدوار فوراً.

### ب. جدول الأدوار والصلاحيات
- يعرض **الدور الوظيفي** (بالاسم العربي والوصف)، و**الصلاحيات الممنوحة** (بشارات عربية مقروءة)، و**النوع** (`نظامي أساسي` محمي من الحذف، أو `دور مخصص` يظهر بجانبه زر **«حذف»**).

### ج. جدول إدارة المستخدمين
- يعرض كل حساب في المنصة مع الأعمدة التالية:
  - **الاسم والبريد الإلكتروني.**
  - **الحالة:** قائمة منسدلة معربة لتبديل حالة المستخدم فوراً بين (`نشط`، `بانتظار اعتماد الإدارة`، `بانتظار تأكيد البريد`، `موقوف`).
  - **الدور الوظيفي:** قائمة منسدلة معربة بجميع الأدوار النظامية والمخصصة لإسناد الدور مباشرة وتفعيل صلاحياته لحظياً.

## 6. التبويب الخامس: 📋 سجل التدقيق

يوثق كل العمليات الحساسة والإدارية والتحريرية في المنصة ([`AuditLogsViewer.tsx`](../apps/web/src/admin/AuditLogsViewer.tsx)).

### أ. شريط التحكم والبحث والتصدير
- **مربع البحث (`ابحث في سجل التدقيق...`):** بحث عربي مطبّع فوري يبحث في التوقيت، اسم الفاعل، الإجراء، الهدف، وجملة التفاصيل الكاملة.
- **زر «📤 تصدير ومشاركة»:** يفتح نافذة منبثقة لتصدير السجلات المعروضة (أو نتائج البحث المصفّاة حالياً) بأحد خيارين:
  1. **📊 تصدير ومشاركة ملف إكسل (XLSX):** يولّد مصنف Excel حقيقي من اليمين لليسار (`RTL`) بأعمدة عربية واضحة تشمل التوقيت، الفاعل، الإجراء، الهدف، التفاصيل، البريد الإلكتروني، وعنوان الاتصال، مع تنسيق الرؤوس وعرض الأعمدة.
  2. **📄 تصدير ومشاركة مستند PDF عربي:** يولّد مستند PDF متعدد الصفحات مرسوماً بخط عربي سليم الاتجاه والتشكيل دون تقطع في الحروف، جاهزاً للطباعة أو المشاركة.
  - عند التصدير يُنزَّل الملف مباشرة على جهازك، وتُفتح نافذة المشاركة الأصلية للمتصفح تلقائياً إذا كانت مدعومة في جهازك.
- **زر «🔄 تحديث»:** يعيد جلب أحدث السجلات من قاعدة البيانات.

### ب. جدول سجل التدقيق
| العمود | المحتوى المعروض |
| :--- | :--- |
| **التوقيت** | تاريخ ووقت الحدث بصيغة عربية واضحة. |
| **الفاعل** | اسم المستخدم فقط (أو «النظام» في العمليات التلقائية) دون عرض البريد الإلكتروني في الجدول. |
| **الإجراء** | ترجمة عربية دقيقة لطبيعة العملية المنفذة. |
| **الهدف** | وصف عربي للكيان المستهدف واسمه عند توفره. |
| **التفاصيل** | جملة عربية مقروءة تلقائياً بصيغة: **«في تمام [التوقيت] قام [الفاعل] بـ [الإجراء] على [الهدف]»**، وبجانبها زر **«🔍 تفاصيل أكثر»**. |

### ج. نافذة «🔍 تفاصيل أكثر» المنبثقة
عند الضغط على **«🔍 تفاصيل أكثر»** في أي صف تُفتح نافذة منبثقة تعرض:
- الملخص المقروء الكامل للحدث.
- الاسم الكامل للفاعل والبريد الإلكتروني وعنوان الاتصال (`IP`).
- التوقيت الدقيق والوصف العربي للإجراء والهدف.
